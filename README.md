# BlueHaven AI World

A clean rebuild of BlueHaven AI World: an immersive, rotatable 3D workspace world.

## Stack
- Next.js App Router + TypeScript
- Three.js / React Three Fiber for interactive 3D
- Responsive, accessible interface

## Local development

```bash
npm install
npm run dev
```

## Build verification

```bash
npm run build
```

## Environment
Keep server secrets in deployment environment variables. Never commit API keys or database credentials.
